# Publisher logos

These text logos label the platforms in "Through your library" in the institution
dialog. They are bundled with the app because publishers block hotlinking, and so
the browser fetches nothing from a third party at runtime. A logo only identifies
the platform the library reaches; it does not imply an endorsement or a
relationship with PaperTok.

Every file is a public domain text logo on Wikimedia Commons; the mark belongs to
its owner. Retrieved 2026-10-13. The files are unchanged except that
`sciencedirect.svg`, `nature.svg`, `tandf.svg`, `science.svg` and `iop.svg` gained a
`viewBox` taken from their own `width` and `height`.
